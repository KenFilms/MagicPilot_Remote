Install MagicPilot Remote

Flash MagicPilot onto your M5Stack Core2, CoreS3 or CoreS3-SE straight from the browser. The installer detects the board and writes the matching firmware. You don't need an IDE or a toolchain.

Your browser doesn't support Web Serial. Open this page in Chrome, Edge or Opera on a desktop computer (Windows, macOS, Linux or ChromeOS).
Web Serial only works on a secure page. Open kenfilms.github.io/MagicPilot_Remote/install over https.

Works in Chrome, Edge and Opera on desktop. Safari, Firefox and mobile browsers don't support Web Serial.

How to install

  1. Connect the M5Stack to your computer with a USB-C data cable. Some cables only carry power.
  2. Click Install MagicPilot Remote and select the device's serial port in the browser dialog.
  3. Choose Install MagicPilot Remote. If the device still runs other firmware, such as the M5Stack factory demo, tick Erase device.
  4. Wait one to two minutes until the installer reports that it's done. The device restarts into MagicPilot.
  5. On the camera, switch on Bluetooth. Then tap CONNECT on the remote and enter the 6-digit PIN the camera shows.

Flashing replaces the firmware on the M5Stack only. Presets on the microSD card are not touched.

Firmware files

BoardChipImage (flash at 0x0)
M5Stack Core2ESP32MagicPilot_Remote_m5stack-core2.bin
M5Stack CoreS3 / CoreS3-SEESP32-S3MagicPilot_Remote_m5stack-cores3.bin

To flash an image yourself, use esptool:

esptool.py --chip esp32   write_flash 0x0 MagicPilot_Remote_m5stack-core2.bin
esptool.py --chip esp32s3 write_flash 0x0 MagicPilot_Remote_m5stack-cores3.bin

Troubleshooting

The device doesn't appear in the port list

Try another USB-C cable or port; many cables carry power only. Depending on the revision, the Core2 uses a CP2104 or CH9102 USB-to-serial chip. On Windows or older macOS versions, you may need the driver from the chip vendor, for example the Silicon Labs CP210x driver.

CoreS3 / CoreS3-SE fails to connect or stops during flashing

Put the CoreS3 into download mode: press and hold the reset button for about 3 seconds until the green LED lights up, then click Install again. When flashing has finished, press reset once to start MagicPilot.

"Failed to open serial port" or the port is busy

Close every other program that uses the port, such as the Arduino IDE serial monitor, pio device monitor or another browser tab with this installer.
